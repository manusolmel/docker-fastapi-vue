# Docker FastAPI + Vue

Primer proyecto de prueba con Docker, creado como ejercicio inicial durante las prácticas.

## Descripción

Aplicación sencilla formada por:

- **FastAPI** como API backend.
- **Vue + Vite** como frontend.
- **PostgreSQL** como base de datos.
- **Nginx** como proxy para unir los servicios.
- Configuración básica con **Docker Compose** y manifiestos de Kubernetes.

El proyecto queda conservado como referencia secundaria dentro del repositorio, con una descripción breve y sin documentación extensa.

## Rama principal

La rama visible/principal del proyecto es `main`.
